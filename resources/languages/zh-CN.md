# Typing 用户指南

Typing 通过可配置的键盘命令，让您在前台应用中移动光标和编辑内容。开启命令模式后可使用单键命令，也可以按住已配置的修饰键使用快捷键。当前使用的映射配置决定每个按键的作用。

## 开始使用

1. 将便携版 ZIP 解压到一个文件夹。请将 `Typing.exe`、`inputsim.dll`、`configuration.ini` 以及 `profiles` 和 `languages` 文件夹放在一起。
2. 退出使用相同全局切换快捷键的旧版 Typing 或 Aldetl。
3. 运行 `Typing.exe`。Typing 默认启用，并在 Windows 通知区域（系统托盘）中运行；主窗口保持隐藏。
4. 打开文本编辑器，将光标放入文字中。
5. 使用默认配置时，单独轻按并释放 **Caps Lock** 或 **Left Alt** 即可进入命令模式。按 **I**、**J**、**K**、**L** 分别向上、左、下、右移动。
6. 再次轻按模式键，或按 **G**，即可退出命令模式并恢复普通输入。默认也会在空闲后自动退出命令模式。

以下示例使用附带的 Default 配置。请在**映射配置**中查看或编辑配置。主窗口的标签依次为**映射配置**、**事件诊断**、**设置**、**帮助**。

## 启用、停用和退出

启用 Typing 后，应用会识别您配置的命令。命令模式是独立状态：Typing 可以保持启用，同时关闭命令模式。

使用以下控件管理 Typing：

| 控件 | 作用 |
| --- | --- |
| 默认的 **Ctrl+U** | 切换 Typing 的启用或停用状态。 |
| 双击托盘图标 | 切换 Typing 的启用或停用状态。 |
| 托盘中的**启用**或**停用** | 同一个切换菜单项启动或停止键盘处理；名称表示下一步操作。 |
| 托盘中的**显示窗口** | 打开主窗口。 |
| 关闭或最小化主窗口 | 隐藏窗口，让 Typing 继续在托盘中运行。 |
| 托盘中的**退出** | 退出 Typing。 |

托盘菜单依次列出**显示窗口**、**启用/停用**、**退出**。停用时，应用先完成输出清理，再停止识别。如果清理失败，可以通过托盘切换项重试状态切换。

**帮助**页面提供简短介绍，以及 Vim、Emacs 风格的光标移动和快捷键映射示例。选择示例下方的**打开用户指南…**，可在单独的可调整大小的对话框中阅读完整指南，其中包含标题、列表、表格和行内格式。指南只读且可滚动，可以选择和复制文字。使用**关闭**、**Escape** 或标题栏关闭按钮返回帮助。选择旁边的**关于**查看应用版本。

## 使用命令模式和快捷键

单独按下并释放**模式键**会切换命令模式。按住模式键并按其他键，也可以执行已配置的快捷键。例如，默认的 **Caps Lock+J** 无需先进入命令模式，即可向左移动。

类型为**命令模式**的映射在命令模式中执行。类型为**快捷键**的映射在 Typing 启用时也可在命令模式关闭的情况下执行。未匹配的输入会传递给前台应用。

启用光标提示后，光标附近的高亮会表示命令模式或 Caps Lock 状态。两者同时生效时，会显示两个不同颜色的半圆。托盘图标也会区分停用、启用和命令模式状态。

### 使用默认配置移动和编辑

以下按键在命令模式中执行：

| 按键 | 作用 |
| --- | --- |
| **I / J / K / L** | 向上 / 左 / 下 / 右移动。 |
| **H / P** | 向左 / 右移动一个单词。 |
| **U / O** | 移动到行首 / 行尾。 |
| **N / M** | 向上 / 下翻页。 |
| **Left Shift** 加移动键 | 移动时选择文字。 |
| **E / R** | 删除 / 退格。 |
| **F / D / S / A** | 将移动步数设为 1 / 2 / 5 / 10。 |
| **V** | 切换后续移动的选择状态。 |
| **Q** | 请求与最近记录的移动方向相反的移动。 |
| **Y / T** | 输入本地日期 / 时间。 |
| **G** | 退出命令模式。 |

步数会应用于下一次移动尝试。对于可以反向移动的方向组合，步数会继续用于这一组方向，直到更改步数或重置命令模式。例如，先按 **S**，再按 **J**，会向左移动五次；随后按 **L** 会向右移动五次。在移动前按 **F** 可将步数恢复为一。行首和行尾移动不会保留步数。

**Q** 会反转已记录的移动，不会撤销文档编辑。要撤销编辑，请使用前台应用通常的撤销快捷键，例如 **Ctrl+Z**。

选择状态会为移动输出附加 Shift。再次轻按 **V** 可关闭选择。退出命令模式会清除选择状态和移动步数；进入命令模式也会清除移动历史。

默认配置将 Caps Lock 用作模式键。按住 **Caps Lock**，再按 **Space**，即可切换操作系统的大小写锁定状态。映射编辑器中的 **Caps Lock** 动作提供此切换功能（配置文件中可写为 `CapsLock` 或 `capslock`）。默认配置中的右 Shift 组合不再切换大小写锁定。当 Caps Lock 用作模式键时，与其他按键重叠会抑制其原有的大小写锁定功能；只有单独轻按并释放才会切换命令模式。

## 自定义映射

打开主窗口并选择**映射配置**。每个映射配置都是独立的 `.typing.ini` 文件，包含模式键、命令模式映射和快捷键。

### 编辑和启用配置

1. 从**配置**下拉列表中选择已保存的配置，打开后可进行编辑，但不会改变当前使用的配置。列表只显示应用 `profiles` 目录中的名称，不包括子目录或其他位置。
2. 使用**新建**创建有名称的空白草稿，或使用**复制**复制正在编辑的映射并指定名称。复制操作包含尚未保存的映射更改，不会更改源文件。
3. 使用表格上方**按键映射：添加、编辑、删除**操作。每条映射都有**启用**状态、**类型**、**触发键**、**动作**和**诊断**。可以直接输入触发键，也可以选择**录制触发键**，按下并释放有效快捷键，将其填入字段。无效或已停止的录制不会更改原值。**录制输出**使用相同流程。**停止录制**会结束监听并保留字段内容。类型可选择模式键、命令模式或快捷键，然后选择动作及参数。确认会更新草稿；取消会保留原映射。
4. 使用**保存**写入更改。新建、复制和导入的配置会保存在默认配置目录中。保存不会改变正在运行的映射。选择下拉列表旁的**设为当前配置**，保存待处理的更改，并在输出清理完成后启用当前显示的配置。

点击**类型**、**触发键**或**动作**表头可按文字排序。再次点击同一表头可反转顺序；箭头表示排序方向。排序会保留所选映射，并将仅有诊断的行放在底部。它只改变显示顺序，不会改变配置文件或保存顺序。

使用表格或添加/编辑对话框中的**启用**复选框，可以保留映射但停止使用它。新映射默认启用。停用的映射仍保留触发键和动作，但不会处理按键；停用模式键后，该键也不会进入命令模式。保存会持久化状态，**设为当前配置**会使其生效。复制和导入保留停用状态。使用停用映射的配置会保存为格式版本 2，旧版客户端无法打开。

页面显示当前使用和正在编辑的配置名称，不显示路径，并区分未保存更改、已保存但未使用的文件和正在使用的已保存版本。如果启用失败，可再次使用**设为当前配置**重试。快捷键录制会保留左右修饰键的区别，录制全局切换快捷键时不会执行它。

### 管理配置

使用以下操作管理配置文件和编辑内容：

| 操作 | 作用 |
| --- | --- |
| **保存** | 写入正在编辑的配置，不改变运行中的映射。 |
| **设为当前配置** | 保存并启用当前显示的配置，也可重试失败的启用操作。 |
| **另存为** | 选择任意可写目标。保存在默认配置目录之外的文件不会出现在下拉列表中；导入副本后可使其出现在列表中。 |
| **重命名** | 指定唯一显示名称，然后保存更改。文件名保持不变。 |
| **新建** | 创建有名称的空白草稿。保存后加入下拉列表。 |
| **复制** | 根据当前映射创建有名称的草稿，包含未保存更改；保存为独立配置。 |
| **删除** | 选择未使用的可用配置，并确认删除。当前使用的配置不会列出；删除前需先将其他配置设为当前配置。 |
| **导入** | 选择映射配置或旧版 INI，为导入草稿命名，再保存到默认配置目录。源文件保持不变。 |
| 最小化主窗口 | 将正在编辑的副本保留在内存中。 |
| 关闭主窗口、替换正在编辑的配置、删除正在编辑的配置或退出 | 出现提示时选择保存、不保存或取消。取消会继续编辑；不保存会放弃更改。 |

保存时会检查外部文件更改，并将原目标文件备份到同目录的 **.bak** 文件。新建、复制、导入和重命名要求可用配置名称唯一。空配置表示没有映射和模式键。

### 按键名称和文件表示法

使用**录制触发键**或**录制输出**可获得正确的快捷键名称。手动输入时，将修饰键放在最终按键之前，并使用 `+` 分隔，例如 `LMenu+C` 或 `Control+Shift+Left`。左右修饰键使用不同名称：

| 修饰键 | 左键 | 右键 |
| --- | --- | --- |
| Control | `LControlKey` | `RControlKey` |
| Shift | `LShiftKey` | `RShiftKey` |
| Alt | `LMenu` | `RMenu` |

Caps Lock 的名称为 `CapsLock`。需要区分左右时，请使用明确的左右名称。Default 配置将 Caps Lock 和 Left Alt 声明为模式键；两者都可以单独轻按进入命令模式，或用于已配置的快捷键。

直接编辑配置文件时，使用 `Trigger=Action`。例如，`LMenu+C=Control+C` 将左 Alt+C 映射到 Ctrl+C。`[modekeys]` 包含 `CapsLock=mode` 这样的模式键声明，以及 `J=Left` 这样的命令模式映射；`[hotkeys]` 包含在命令模式关闭时也能使用的快捷键。`[profile]` 节包含配置名称和格式版本。

在版本 2 中，`!J=Left` 表示停用该映射，`J=Left` 表示启用。以 `;` 开头的行是注释，不会显示为可编辑映射。若希望以后重新启用映射，请使用启用状态保留它。要设置移动步数，在编辑器中选择**移动步数**并输入正整数；文件表示法为 `stepN`，例如 `F=step1`。

## 更改应用首选项

在**设置**的**语言**下拉列表中选择**系统默认**、**English** 或 **简体中文**。界面会立即切换，保留正在编辑的映射和运行中的映射。Typing 将选择按用户保存在 `%LOCALAPPDATA%\Typing\language.txt` 中。语言切换失败时会保留原选择并显示错误；启动时若无法加载已保存的语言配置，则使用英文。

语言配置是应用 `languages` 目录中的 UTF-8 `.ini` 文件，与按键映射配置分开。使用稳定的消息 ID 即可更新翻译，无需重新构建 Typing。缺少的翻译使用英文。匹配的 `.md` 文件提供完整指南；缺少时使用完整的英文指南。文件会在启动和选择其他语言时加载。编辑当前语言文件后，请切换到另一种语言再切回，或重新启动。系统语言更改会在下次启动，或切换离开系统默认后再切回时生效。语言选择不会改变键盘布局、输入法、配置文件表示法或日期/时间命令输出。系统管理的对话框按钮和 Windows 错误描述可能仍使用 Windows 的语言。

在**设置**中勾选**随 Windows 启动**，可在登录时让 Typing 在系统托盘中启动。取消勾选可关闭自动启动。更改立即生效，无需保存或应用，且仅影响当前 Windows 用户。此选项在您启用之前保持关闭。更改它不会停止正在运行的应用，也不会改变映射。

移动便携版文件夹后，请从新位置重新启用该选项。更改失败时，设置会显示错误并保留原复选框状态。无法读取设置时，可重新打开设置以重试。Windows 启动应用控制或组织策略也可能单独阻止自动启动。

其他应用首选项位于可执行文件旁的 `configuration.ini`，包括全局启用/停用快捷键、自动退出命令模式和光标提示。编辑此文件后需重新启动 Typing。

附带设置为 `hotkey=Control+U`、`mode_auto_exit=on`、`mode_auto_exit_time=2`。光标提示接受 `mode_cursor_tip=on` 或 `off`，也支持旧名称 `mode_mouse_tip`。两者同时存在时，以 `mode_cursor_tip` 为准，但两个值都必须有效。

成功启用配置后，会在 `[profiles] active` 中记住配置选择。相对路径从 `configuration.ini` 所在目录解析。

Typing 将窗口大小和诊断日志保存在 `%LOCALAPPDATA%\Typing` 中；该位置不可用时，会对这些文件使用用户目录和临时目录备用位置。语言首选项单独使用 `language.txt`，无法保存时会显示语言切换错误。诊断日志自动在后台记录故障排查信息，跨启动保留历史，包含 `typing.log` 和最多三个归档（`typing.log.1` 至 `.3`），每个文件上限为 1 MiB。旁边可能保留用于协调访问的 `.lock` 文件。

日志失败会被静默忽略。日志繁忙时可能丢弃消息，退出时最后几条消息也可能丢失。日志不会为了等待磁盘写入而阻止应用继续运行或退出。普通日志包含状态切换上下文和故障，不记录您的输入内容或每次成功命令。

## 故障排查

如果 Typing 的表现不符合预期，请检查以下情况：

| 现象 | 检查方法 |
| --- | --- |
| 启动时没有主窗口 | 查看 Windows 通知区域，并选择**显示窗口**。 |
| 命令键输入了字母 | 确认 Typing 已启用，进入命令模式，并检查当前使用的配置。自动退出可能已恢复普通输入。 |
| 保存的映射没有生效 | 选择配置进行编辑，然后使用**设为当前配置**。仅保存不会改变运行中的映射；启用失败时可再次使用该按钮重试。 |
| 启动时报告应用配置无效 | 修正所报告路径中的文件，然后重新启动。Typing 会在启动键盘处理之前退出，并保留文件不变。 |
| 启动时打开配置恢复页面 | 在映射配置中选择有效配置，或创建并保存配置，然后设为当前配置。恢复成功前，命令保持不可用。 |
| 无法注册全局切换快捷键 | 退出使用相同快捷键的其他 Typing 或 Aldetl，或配置不同快捷键后重新启动。 |
| 关闭窗口后 Typing 仍在运行 | 使用**停用**停止命令识别，或使用托盘中的**退出**结束应用。 |
| 语言未切换或启动后显示英文 | 查看设置中的语言错误，检查语言文件及保存首选项的位置。修复文件后切换离开该语言再切回，或重新启动。 |

**事件诊断**标签显示键盘输入事件。使用**显示键盘事件**控制是否显示，事件表格会占据可用空间。使用复选框旁的**清除**可清空显示历史，不改变键盘监听或复选框状态。
