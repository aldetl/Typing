# TypingVE 1.5.2

TypingVE 1.5.2 provides portable Windows x64 and x86 packages with English and Simplified Chinese interfaces.

## Changes

- Use `TypingVE.exe` to launch the application. Windows file properties, the tray, application windows, guides, and package instructions consistently identify the product as TypingVE.
- Keep existing configuration, mapping profiles, language preferences, window preferences, and startup settings compatible.
- Retain keyboard navigation, direct shortcuts, profile editing, and the default **Caps Lock+Space** capitalization shortcut.

## Upgrading from 1.5.1

Exit the running application before replacing its executable and matching `inputsim.dll`. Extract the complete package into a new folder, or preserve your `configuration.ini` and `profiles` folder when updating an existing portable folder. Launch `TypingVE.exe` and enable **Start with Windows** again if your startup entry points to a different executable path.

Existing profiles keep their explicit bindings. This release does not reset your profiles or migrate per-user data.

## Packages and verification

- **x64:** Windows 11 x64 portable package.
- **x86:** Windows 7 SP1/Windows 10 target, also usable on Windows 11 through WOW64.

Verification runs on Windows 11 x64, including x86 through WOW64. Clean-machine deployment, actual Windows 7/10 execution, physical-key and sleep/session transitions, and full manual display/accessibility coverage remain unverified. These are compatibility targets rather than claims that every target OS has been tested.

The Microsoft Store package remains at its separately prepared version; this release publishes portable packages only.
